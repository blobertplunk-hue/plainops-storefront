Relative Density Day 2: Evidence Review

Use water as the reference point

An object’s position in water gives evidence about its density compared with water. An object that floats is less dense than water; an object that stays suspended has about the same density as water; an object that sinks is more dense than water.

Only claim what the evidence supports

Sink-or-float results tell you about relative density. They do not, by themselves, prove size or mass. Use only the property that was actually observed or measured.

Stable layers reveal an order

When liquids form stable layers, the denser layer is below the less-dense layer. In a stable layered system, density increases as you move downward.

Relative density is a physical property

Relative density is one observable physical property used to classify matter. Other physical properties in the unit include temperature, mass, magnetism, and physical state.
